# specs/

Her yeni özellik için önce buraya kısa bir şartname yazılır, onaylanır, sonra kod yazılır.

Şablon:

```
# <özellik adı>

## Amaç
Tek cümlede ne çözüyor.

## Kapsam
Yapılacaklar / yapılmayacaklar.

## Veri
Hangi tablolar okunuyor, hangileri yazılıyor.

## Kabul kriterleri
Nasıl "bitti" denir.

## Riskler
Neyi bozabilir.
```

Kod yazıldıktan sonra şartname gerçekleşen duruma göre güncellenir.
